One line roasting the entrant's own AI agent — a single line of at most 200
characters, funny and playful, never hateful. `LINE.txt` holds the roast;
`main.ts` checks it is one line of 1 to 200 characters and writes it to
`/output/entry.txt` for the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
